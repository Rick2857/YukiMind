# Yuki-QQbot 2.0.0

2.0.0 是一次面向长期维护的破坏性架构精简。它删除已经脱离主链路的兼容层，让 Planner 成为普通聊天唯一的决策边界，同时保留现有数据库和 Plugin API v1 数据兼容性。

## 主要变化

- 删除第二套管理员自然语言意图路由，管理员操作统一进入 Yuki Agent 工具循环。
- 删除旧自主群聊候选器、置信度、冷却和小时计数链路；群聊参与统一由 Planner 与群开关决定。
- 删除未使用的能力执行包装器、旧 AI 命令包装器及生产包中的测试 Fake。
- Planner 和上下文构建器改为消息处理链的必需依赖，移除静默创建测试依赖的生产兼容分支。
- 修复 Planner 回退时错误清空已授权工具组，以及明确语音、表情请求被错误降级的问题。
- Planner 实际模型名改为从 `MODEL_PROFILES_FILE` 的任务路由读取并写入运行记录。
- 超级管理员能力目录同步为 131 项可修改配置。

## 升级注意

- 本版删除 `PLANNER_ENABLED`、`PLANNER_MODEL`、`ALLOWED_PRIVATE_USERS`、全部 `AUTONOMOUS_*` 环境变量及对应 `autonomous.*` 运行时配置。
- 请根据最新 `.env.example` 清理本地 `.env`；Planner 模型应通过 `MODEL_PROFILES_FILE` 中的 `routes.planner` 配置。
- 数据库版本仍为 Alembic `0018`，从 1.9.0 升级不会清空人物、事件、记忆、关系、插件、自动化、表情或语音数据。升级前仍建议完整备份 `data/`。
- Plugin API 仍为 `1.0`。第三方插件若将 `yuki_requires` 上限写为 `<2.0`，需要在确认兼容后放宽为 `<3.0`；插件代码与 `plugin_api` 无需改版。

## 质量验证

- Ruff、严格 mypy 和完整 pytest 测试套件通过。
- Alembic 从空数据库升级到 `0018 (head)` 通过。
- Docker Bot 镜像构建、健康检查、OneBot 反向 WebSocket、Planner、表情与语音 Worker 联通验证通过。

## 升级命令

```bash
git pull origin main
docker compose up -d --build
docker compose ps
```

不要使用 `docker compose down -v`，以免删除持久化数据。
