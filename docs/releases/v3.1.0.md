# Yuki-QQbot 3.1.0 发布说明

3.1.0 新增 Memory Mutation V2、Host 管理的声明式插件直达绑定、可信消息提及投影和完整养鲲
游戏插件。Plugin API 主版本仍为 `1.0`；养鲲功能本身不新增数据库迁移，当前开发分支的
Alembic head 为 Memory Mutation V2 的 `0026`。

## 直达绑定

部署者可在启动时配置：

```dotenv
PLUGIN_DIRECT_COMMAND_BINDINGS={"*":"io.github.yuanyeyoutao.kun-game:play"}
```

只有已批准、已启用、运行中的普通用户命令会成为活动路由。匹配仍经过 Yuki 原有群/私聊准入、
消息去重、账本、限流、图片写隔离、权限、真实调用上下文和超时；不可用绑定失败关闭，不回退
Planner。前缀配置变更需要重启。

## 可信提及与养鲲插件

`CurrentMessage.mentioned_user_ids` 向插件公开 Host 已归一化的真实提及，按顺序去重并排除机器人
自身。养鲲 PVP 只接受唯一可信提及，不再把文本 QQ 数字当作目标。

内置插件覆盖养成、PVP、BOSS、拍卖和群小游戏，并把开关、重置、完整清除、刷新、下架、修改和
经济配置隔离到真实 SUPERUSER 的 `admin` 长入口。状态按 `group:<gid>` / `private:<uid>` 隔离，
使用每作用域锁、整状态 CAS、固定消息时间和固定随机 seed 提交。

安装、命令、配置、数据语义和回滚步骤见
[`plugins/io.github.yuanyeyoutao.kun-game/README.md`](../../plugins/io.github.yuanyeyoutao.kun-game/README.md)。
