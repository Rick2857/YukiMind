# Yuki-QQbot 1.8.0

本版本为 Yuki 增加可控、可维护、完全本地运行的 QQ 语音合成能力。

## 主要更新

- 新增独立 `genie-tts-worker`，固定使用 Genie-TTS 2.0.2 和部署者自行准备的 GPT-SoVITS V2/V2ProPlus ONNX 模型。
- Worker 通过 Unix Domain Socket 与 Bot 通信，不开放 HTTP/TCP 端口，运行时关闭网络和自动下载，生产镜像不安装 PyTorch。
- 新增声线档案、多参考风格、确定性风格匹配、原子导入、生成缓存、取消、降级和生命周期事件。
- Planner 支持 `text`、`voice`、`text_and_voice`、`optional` 四种回复模式，但不能指定本地文件、模型或参考音频。
- QQ 语音继续走既有发送序列；只有 OneBot 发送边界才会读取 WAV 并编码为 Base64 `record`。
- 新增 `/ai voice`、`qq-ai-bot-cli speech`、自然语言管理员动作、自动化语音动作和 Plugin API v1 `SpeechFacade`。
- 新增非破坏性 Alembic `0015`，保留现有人物、聊天、记忆、关系、视觉、表情、插件和自动化数据。
- 新增独立模型转换工具、12 篇语音文档、健康状态、Docker `speech` profile 和 CI 验证。

## 升级

纯文字用户无需准备任何语音文件：语音默认关闭，按原方式更新即可。

```bash
git pull origin main
docker compose up -d --build
```

启用语音前，请先阅读 `docs/speech/offline-setup.md`，自行准备 GenieData、合法的 ONNX 声线和参考音频，再配置 `.env` 并启动：

```bash
docker compose --profile speech up -d --build
```

仓库和镜像不会附带、下载或提供任何角色模型、原始语音或在线 TTS 凭证。模型与音频的授权责任由部署者承担。
