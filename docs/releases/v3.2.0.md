# Yuki-QQbot 3.2.0 发布说明

3.2.0 让 Yuki 在 Memory V2 中拥有自己的长期记忆。Yuki 可以基于当前真实对话形成偏好、经历、
反思和原则，之后只在相关问题中按需召回；静态核心人格、系统规则、安全规则和权限规则不会被
动态自我记忆覆盖。Plugin API 主版本仍为 `1.0`，Alembic head 更新为 `0027`。

## 自我记忆

- 新增 `self` 作用域与 `current_self` 检索目标，继续复用 Memory V2 的 FTS、Embedding、
  混合 RRF、版本链、冲突、生命周期、上下文预算和使用统计。
- Planner 只有在用户询问 Yuki 自己的过去、经历、长期偏好、观点变化、反思或自我认识时才会
  开启 `self_recall`；普通问候、知识问题和普通任务不会固定加载自我记忆。
- SELF 事实支持 `global`、`private`、`group` 可见范围。候选 SQL 在 FTS 与 Embedding 前完成
  硬过滤，私聊经历不会泄露到其他用户或群，群经历也不会跨群召回。

## 自主读写

- 统一 `memory_change` 支持创建、纠正、撤销、恢复、争议和合并 SELF 记忆；写入必须绑定当前
  永久账本中的真实入站消息，不能使用 Yuki 自己的普通回复或隐藏推理作为唯一证据。
- SELF category 使用 `self_fact`、`self_preference`、`self_episode`、`self_reflection`、
  `self_principle`。工具 Schema 和失败回执都会给出合法列表，便于 Yuki 自行纠错。
- 新增只读 `get_self_memories`，无参数时展示当前会话可见总览，也可按自然语言主题检索；结果
  不包含可见用户/群 ID、原始证据身份或内部审计信息。
- 动态记忆不能修改名字、年龄、生日、核心外貌、核心人格、安全、系统、权限和运行时保护键。

## 可靠性修复

- 基于当前真实群消息启动的自主回应可以使用 `memory_change`；定时任务、系统任务和无真实事件
  的后台流程仍无法取得记忆写权限。
- 自动化意图检测按句判断，避免跨句时间词和动作词错误覆盖 Planner 已选择的 memory 工具域。
- Planner scope、最终有效 scope 和实际暴露工具名继续写入结构化日志，便于排查工具过滤。

## 升级

升级前建议备份 `data/`，然后运行：

```bash
uv run alembic upgrade head
```

`0027` 是非破坏性迁移：现有 person、person_group、group 事实保持不变，旧事实的 SELF 可见范围
字段为空。功能开关默认为关闭；部署者确认迁移与隐私策略后设置：

```dotenv
SELF_MEMORY_ENABLED=true
```
