# Yuki-QQbot 3.0.3 发布说明

3.0.3 为日常表情节奏补丁。Planner 会根据当前精确会话近期的真实表情投递比例，限制未被用户
明确要求的 `optional` 表情；明确索要表情的确定性发送路径保持不变。本版本不新增数据库迁移，
不清理或改写聊天、人物、记忆、关系、自动化或表情数据，Alembic head 保持 `0024`。

## 日常表情频率

- 新增 `emoji.spontaneous_frequency`，默认 `0.15`，取值范围为 `0..1`。
- 配置支持全局、群和用户作用域，并可通过现有管理员自然语言配置工具热修改。
- Planner 复用本轮已经读取的近期账本，不新增模型调用或数据库查询。
- 连续分段发送按一次 Bot 回复计算，最多统计近期 20 次回复。
- 近期自发表情比例达到目标频率时，后端将日常 `optional` 约束为 `none`。
- 用户明确请求表情时不受该目标频率影响。
- 现有同表情冷却、作用域冷却、候选选择、真实 OneBot 回执和故障恢复规则继续生效。

## 文档与资源

- 新增 `docs/architecture/memory-change.md`，作为 Yuki 自主记忆更改、普通用户自然语言修改和
  统一防双写接口的讨论草案；本版本不实现或开放新的记忆写能力。
- 原部署新增项目头像资源；因公开快照未确认原图再分发授权，本仓库不包含该文件。

## 配置示例

```dotenv
EMOJI_SPONTANEOUS_FREQUENCY=0.15
```

管理员也可以用自然语言将它设置到全局、当前群或指定用户作用域。`0` 表示禁止日常自发表情，
`1` 表示频率预算不限制日常表情，但 Planner 仍会根据语义判断是否适合使用。

## 升级

```bash
git pull origin main
docker compose up -d --build bot
```

NapCat 容器与 QQ 登录数据不需要重建。部署方可以继续使用默认值，也可以在 `.env` 中显式加入
`EMOJI_SPONTANEOUS_FREQUENCY`。

## 验证重点

- 在同一私聊或群聊中连续进行普通对话，确认日常表情不会持续超过目标比例；
- 将频率设置为 `0`，确认日常 `optional` 被禁止，而“发个表情”等明确请求仍能发送；
- 将频率按群或用户热修改，确认只影响对应作用域；
- 确认连续分段文字和表情只计为一次回复；
- 确认没有新增 Alembic 迁移，既有数据保持不变。
