# Yuki-QQbot 1.8.2

这是 1.8 本地语音系统的第二个补丁版本，重点修复语音元数据进入聊天上下文、Planner
语音决策和媒体工具空回复问题，并完善人物级语音偏好。

## 主要更新

- Planner 成为聊天语音的统一决策边界，按自然语言理解本轮语音请求、拒绝和持续偏好。
- 新增每个 QQ 独立的 `text_only`、`auto`、`prefer_voice` 持久语音偏好。
- 新增 `speech.spontaneous_frequency`，控制用户未主动要求时的日常语音目标频率。
- `send_voice` 只在 Planner 确认本轮明确索要语音时开放，Agent 只能选择风格和语言。
- 修复 Planner 合法 JSON 枚举和自定义原因码被误拒绝后回退的问题。
- 修复语音或普通可选表情工具调用后，模型最终正文为空导致整轮不发消息的问题。
- 修复 `[语音：Yuki 发送了一条语音，声线：…]` 等内部 TTS 元数据进入模型上下文的问题；
  实际朗读正文与结构化媒体信息现在严格分离。
- 包含语音的回复中，Yuki 的自称改写为 `ゆき`，避免日语 TTS 按英文字母朗读。
- 支持通过 `PLANNER_MODEL=deepseek-v4-flash` 为 Planner 使用独立的低延迟模型，不改变主聊天模型。
- 新增非破坏性 Alembic `0017`；保留人物、聊天、记忆、声线和语音生成记录。

## 升级

升级前先备份 `data/`，然后执行：

```bash
git pull origin main
docker compose --profile speech up -d --build
```

升级后可以检查：

```bash
docker compose exec -T bot qq-ai-bot-cli speech status
docker compose exec -T bot qq-ai-bot-cli speech genie doctor
```

NapCat 登录数据不会被迁移或重置。Release 说明文件以 UTF-8 保存。
