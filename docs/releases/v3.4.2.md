# Yuki-QQbot 3.4.2 发布说明

3.4.2 为 GitHub Monitor 的 Release 事件补齐中文 PNG 卡片。它沿用 3.4.1 Push 卡片的暗色
视觉体系和持久媒体投递链路，不改变 Plugin API，也不新增数据库迁移。

## Release 卡片

- 展示仓库、发布者、北京时间和版本标签。
- 区分正式版、预发布与草稿，并展示目标分支和附件数量。
- 展示版本名称与最多三行发布说明；长文本按像素宽度安全换行和省略。
- 使用容器内中文字体本地渲染，不读取远程字体或图片。
- `send_card=false` 的目标仍只接收文本；其他 GitHub 事件的行为保持不变。

## 实现与兼容性

- GitHub Monitor 插件版本提升至 `1.1.0`。
- Release 事件归一化只保留渲染所需的有界字段，不向卡片链路传入完整原始响应。
- Push 与 Release 通过统一卡片分发入口进入已有媒体制品和通知 Outbox。
- Yuki 版本提升至 `3.4.2`，Plugin API 保持 `1.1`，Alembic head 保持 `0028`。

## 升级

升级前仍建议备份 `data/`。只重建 Bot 可以保留 NapCat 容器和 QQ 登录状态：

```bash
docker compose up -d --build --no-deps bot
```

现有 GitHub Monitor 仓库、目标、Token、cursor 和通知历史都会保留。插件权限未增加；若 Host
因源码或版本变化将插件标记为待批准，由超级管理员重新批准并启用即可。

## 发布验证

- GitHub Monitor 事件、渲染、轮询和 Host 通知媒体测试通过；
- 插件 manifest、权限、入口、注册、启动和停止契约测试通过；
- 1200×630 中文 Release 卡片已实际渲染并检查长文本布局；
- Bot 镜像构建与健康检查通过，NapCat 容器和 QQ 登录状态保持不变。
