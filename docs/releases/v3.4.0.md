# Yuki-QQbot 3.4.0 发布说明

3.4.0 将 scheduled automation 从固定能力脚本升级为受真实创建者权限约束的自由 Agent。
用户消息和后台任务现在共用工具内核与普通插件注册；Planner scope 用于首批工具优先级，不再
覆盖或截断其他已授权能力。Plugin API 仍为 `1.0`，本版本不新增数据库迁移，Alembic head
保持 `0027`。

## 自由 Agent 与工具域

- Planner 显式选择的 scope 只决定首批暴露工具；Agent 可通过 `request_tools` 按需加载当前
  origin、身份和权限允许的其他工具。
- automation 识别只向 Planner scope 集合追加能力，不再覆盖 web、memory、MCP 或 plugin。
- 移除“联网后禁止发送或修改”的人工顺序隔离；权限、目标、真实发送者和运行来源仍由后端
  强制校验。
- Agent 的 Responses continuation 保持已声明 Function/Native Tool 单调累积，动态加载工具
  不会使 DeepSeek 因工具定义消失而返回 HTTP 400。

## Agentic 自动化

- `agentic` TaskSpec 省略 `capabilities` 时继承创建者当前可委托工具域；显式列出能力时只用于
  主动缩小范围。
- scheduled Agent 可在创建者权限内创建、更新、取消、列出和立即运行自动化；子任务使用
  父任务、运行和步骤生成幂等创建键，模型重试不会重复落库。
- 普通会话与 scheduled Agent 共用同一份 TaskSpec Schema。参数错误会返回不含原始输入的
  字段级问题，Agent 可以自行修正，而不是反复收到裸 `invalid_arguments`。
- 当前任务和完成历史统一显示稳定 `automation_id`；查看、暂停、恢复、取消和立即运行不再
  使用每次列表都会变化的临时编号。
- 自动化模型错误按超时、限流、不可用、认证、配置和非法请求分类；失败模型/工具调用会进入
  运行用量，已提交修改不会因最终措辞失败而被错误回复为整体失败。

## 普通插件后台执行

- 插件只注册一次普通 Tool；声明支持 `scheduled_automation` 后，Host 自动把同一注册投影到
  自动化能力目录，不再要求维护第二套聊天/自动化接口。
- 后台插件调用获得真实 origin、创建者、当前群、委托权限和主动发送 Gateway。
- 网易云音乐分享工具支持用户消息与 scheduled automation，可直接发送歌曲或专辑，并把
  真实发送结果计入自动化运行审计。
- 已人工验证“联网查询 → 发送网易云歌曲 → 创建五分钟后子提醒”的完整链路，子任务能以稳定
  ID 持久化并按时进入活动任务列表。

## DeepSeek Responses 可靠性

- 多轮续写会持久保留 `function_call → function_call_output` 配对；三轮及以上工具调用不再因
  丢失旧输出而被 DeepSeek 拒绝。
- continuation 切换 Tavily 回退时会正确重置 Provider 状态；不支持原生 Tool 的
  Chat-Completions Profile 会在首轮前直接采用已授权 Tavily fallback。
- 工具调用成功后模型最终化失败时，支持通过持久化回执恢复真实结果，避免“操作成功但最终
  回复报错”。

## Web 路由

- 混合模式下，当前用户消息出现 `Tavily`、`Tavility` 或 `塔维利` 即选择 Tavily，不再依赖
  “用/搜索/访问”等固定句式。
- 域名直达与一次性 native → Tavily 有界回退保持不变；Router 仍不授予 web 权限，也不会
  强迫 Agent 联网。

## 升级

本版本没有数据库迁移。更新后只需重建 Bot；使用 `--no-deps` 可保留 NapCat 容器和 QQ 登录：

```bash
docker compose up -d --build --no-deps bot
```
