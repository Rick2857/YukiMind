# Yuki-QQbot 3.4.4 发布说明

3.4.4 稳定了主 Agent 的 Prompt、历史窗口与工具定义，减少输入顺序或滚动边界变化导致的
缓存失效，并补齐缩短发送者身份头的输出清理。

## Prompt 与历史缓存

- 历史消息位于动态运行时上下文之前，当前触发消息作为独立末尾输入。
- 历史窗口使用高低水位分块滚动；未达到上限时保持相同起点，达到上限后一次滚动到低水位。
- `HISTORY_WINDOW_LOW_WATERMARK_RATIO` 默认设为 `0.67`。
- Prompt 指标分别记录历史和当前消息字符数，并标记本轮是否发生窗口滚动。

## 工具与模型成本

- Core 与 MCP 首批工具采用宽松数量和 Schema Token 预算，未进入首批的工具仍可通过
  `request_tools` 按需加载。
- 工具定义、Flash 候选目录与筛选结果按规范工具名稳定排序，避免同一集合仅顺序不同便使
  Prompt 缓存失效。
- 默认推理深度由 `max` 调整为 `high`；需要更深推理时仍可显式选择 `max`。

## 输出可靠性

- 输出清理器现在能够剥离省略消息 ID、时间或两者的发送者身份头。
- 身份头与正文位于同一行时只移除内部元数据，保留用户可见正文。

## 兼容性与升级

- Yuki 版本提升至 `3.4.4`，Plugin API 保持 `1.1`。
- 本版本不新增数据库迁移，Alembic head 仍为 `0029`。
- 升级前建议备份 `data/`。只重建 Bot 可保留 NapCat 容器与 QQ 登录状态：

```bash
docker compose up -d --build --no-deps bot
```

## 发布验证

- Prompt、历史窗口、工具排序和输出清理均有单元测试覆盖。
- 本版本不包含语音识别功能。
