# Yuki-QQbot 3.0.1 发布说明

3.0.1 是 3.0.0 正式版后的性能与交互补丁，不新增数据库迁移，不清理或改写现有聊天、人物、记忆、关系、自动化和表情数据。Alembic head 继续保持 `0024`。

## 主要更新

### 更快的日常回复

- 主聊天支持 DeepSeek V4 Flash 的 `high / max` 推理深度，当前部署可使用 Max。
- Planner 新增 `none / lexical / hybrid / overview` 四级记忆检索计划：简短聊天不再默认调用 Embedding，需要长期人物事实、偏好或历史语义匹配时才进入混合检索。
- 相同语义查询增加有界的短期 Embedding 缓存。
- 日常分段消息间隔调整为 1–2 秒；第一条消息不会被该拟人化间隔延迟。

### 更可靠的表情回复

- 表情由 Planner 原生规划，纯表情回复不再额外调用 Chat Agent，也允许没有文字正文。
- 日常可选表情直接使用本地描述和标签评分第一名，不调用 Qwen 精选。
- 用户明确索要表情且前三个候选难分时才调用 Qwen；视觉精选最多等待 2 秒，失败立即回退本地第一名。
- 新表情仍在后台使用 Qwen 生成描述、情绪标签、使用场景与置信度。

### 更清晰的工具边界

- Agent 仍可通过 `request_tools` 找回因 Schema 预算未预载的工具，但只能在 Planner 本轮批准的 scope 内请求，不能扩大权限范围。
- 表情发送不再同时存在 Planner 和 Chat Agent 两套决策入口；自动化与插件的独立发送接口保持兼容。

### 文档整理

- 根目录 README 改为简洁的项目介绍与快速开始。
- 原完整 README 迁移至 `docs/help.md` 作为详细帮助，并修复所有相对链接。

## 升级

```bash
git pull origin main
docker compose up -d --build
```

本版本无需手工执行新的迁移；容器启动仍会安全执行 `alembic upgrade head`。
