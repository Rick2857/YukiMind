# Yuki-QQbot 1.9.0 重构基线

本基线冻结于 1.9.0 代码修改之前，用于和重构结果做同口径比较。所有场景都使用合成的 QQ 号、昵称、记忆和消息，不包含 `.env`、密钥、真实聊天内容或模型推理。

## 采集信息

- 起始提交：`c4a0910a39a69501a0a49226a64f2cfb6e7a682d`
- Python 源文件：210 个，44,551 行
- Python 测试文件：64 个，15,596 行
- `ApplicationContainer`：1,097 行；构造函数直接绑定约 105 个资源或服务
- `Settings`：单个类，约 199 个字段
- 实际系统提示词：3,677 字符（容器内以 UTF-8/LF 读取）
- Planner 固定提示词：2,699 字符；代表性完整 Planner 输入：4,509 字符
- Token 估算统一使用 `ceil(字符数 / 4)`，只用于前后版本趋势比较，不代替供应商 tokenizer

## 当前容器职责

`ApplicationContainer` 同时负责配置、数据库、全部仓储、模型供应商、联网、视觉、表情、语音、Planner、关系、记忆、管理员能力、自动化、插件、命令、消息处理器、后台任务及生命周期。资源构建顺序、模块依赖和启动/关闭顺序都隐含在同一文件中。

当前直接持有主 `LLMProvider` 的业务位置共 10 类：

1. Chat Agent / AgentRunner
2. Planner
3. MemoryWorker
4. RelationshipEvaluator
5. EmojiReplacementService
6. AutomationCapabilityHandlers
7. AdminIntentRouter
8. PluginAgentSessionService
9. AutonomousGroupService
10. 组合根本身

视觉、表情视觉分类/选择和语音生成另有独立供应商类型，不计入主 LLM 的 10 类。

## 当前模型任务和解析方式

现有任务事实上包括聊天 Agent、Planner、记忆提炼、关系评估、表情替换、自动化文本生成、自动化 Agent、插件 Agent 会话及辅助结构化判断，但没有统一的任务标识、Profile、路由或能力检查。Planner、记忆、关系和表情替换各自拼接 JSON 指令并自行解析；Planner 还接受 fenced JSON、首个平衡对象并在解析后静默裁剪部分字段。

`ChatResponse` 没有 prompt/completion/total token 字段，OpenAI-compatible 供应商也未保存 usage，因此基线的真实 token 用量不可用。数据库没有模型调用账本。

## 当前提示词碎片

常规 Agent 最多组合以下系统片段：`core.identity`、`core.security`、`core.behavior`、`core.time`、`core.tool-guidance`、`core.superuser`、`core.relationship`、`core.memory-scene`、`core.web`、`core.speech-runtime`、`core.visual`/`core.visual-failure`、`core.planner-plan`、`core.final`。每个启用插件再分别加入一层重复的不可信包装。

语音片段会把 Unix Socket 路径、Bot 8080 和 NapCat 6099 等部署细节放入普通模型上下文。Planner schema 与枚举由手写长文本重复描述，工具权限同时分散在名称集合、`startswith` 判断、布尔开关和 prompt 文案中。

## 当前工具暴露面

合成场景的并集为 30 个工具：

`admin_delete_config_override`、`admin_execute_action`、`admin_get_config`、`admin_get_history`、`admin_list_capabilities`、`admin_rollback_change`、`admin_set_config`、`automation_cancel`、`automation_create`、`automation_get`、`automation_history`、`automation_list`、`automation_list_history`、`automation_pause`、`automation_resume`、`automation_run_now`、`automation_update`、`call_onebot_api`、`get_group_memories`、`get_my_capabilities`、`get_person_memories`、`get_recent_chat_history`、`read_webpage`、`search_chat_history`、`send_emoji`、`send_voice`、`time_get_current`、`time_get_timezone`、`time_set_timezone`、`web_search`。

普通私聊预先暴露 21 个工具，其中包含整组自动化能力；超级管理员轮为 28 个。只读与变更型筛选依赖 `_READ_ONLY_TOOL_NAMES`、`_WEB_TOOL_NAMES`、`name.startswith("admin_")` 和各后端自己的 `owns/is_mutating/is_read_only`。

## 1.9.0 比较目标

- 普通私聊完整输入字符至少降低 40%
- Planner 完整输入字符至少降低 50%
- 普通轮不暴露与当前计划无关的工具组
- 稳定系统前缀可计算并复用稳定 hash
- 所有模型任务可追溯到明确 Profile，并记录不含正文的 usage/延迟/错误类别
- 容器、提示词、上下文、能力和结构化输出各只有一个权威组合/校验入口
